# John Ghazzagh portfolio

A static, responsive portfolio made with HTML, CSS, and vanilla JavaScript. No build step is required.

## Publish on GitHub Pages

1. Create a new public repository, such as `portfolio`, and upload the **contents** of this folder to the repository root.
2. In repository Settings → Pages, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. GitHub will provide a URL in the form `https://YOUR-USERNAME.github.io/portfolio/`. All internal links use relative paths, so they work at a project URL or a custom domain.

## Before sharing publicly

- Review the biography, project descriptions, credentials, and contact email in `index.html` and `projects/*.html`.
- The LinkedIn export lists the Instructional Designer position as continuing alongside the coordinator role. This site displays 2022–2024 as the primary period for that role and notes the overlap in the timeline.
- Add verified outcomes or metrics to case studies when available. Current copy describes work and intent without claiming measured results.
- Replace the illustrative project graphics with approved screenshots if desired. Avoid student or faculty information in public screenshots.
- The optional Google Fonts import in `styles.css` gracefully falls back to Arial if blocked. Remove the import for a fully self-hosted site.
- A contact form is intentionally omitted because GitHub Pages does not process form submissions. The email link works without a service.

## Files

- `index.html`: home, interactive challenge, project gallery, résumé summary, and contact.
- `projects/*.html`: four shareable case studies.
- `styles.css`: visual design and responsive layout.
- `script.js`: project filters and challenge interaction.

Edit the text directly in the HTML. No dependency installation is needed.
